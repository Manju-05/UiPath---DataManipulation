#  UiPath - Data Manipulation & Automation

A collection of UiPath RPA workflows focusing on data manipulation, control flow patterns, and iterative data processing techniques.

---

## 📌 Repository Overview

This repository contains UiPath Studio workflows designed to demonstrate essential Robotic Process Automation (RPA) practices, including:

* **Data Manipulation:** Extracting, formatting, and transforming structured and unstructured data.
* **Control Flow & Loops:** Implementing iterative logic (such as For Each, While, and Do While loops) to process collections and data tables efficiently.

---

## 🛠 Tech Stack

* **Tool:** UiPath Studio
* **Language:** XAML / .NET
* **Platform:** Windows (UiPath Core)
